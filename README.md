# AK4490DAC

AKM(旭化成エレクトロニクス)の **AK4490**(32bit プレミアムDAC)と **AK4118**(SPDIFレシーバー)を使ったUSB DACのKiCadプロジェクト。

## 経緯

元の回路図(Eagle形式、`NEWDAC.sch`)はWindows PC上にのみ存在しており、このリポジトリ作成時点では発見できていません。
このプロジェクトは、JLCPCBに発注した際の製造データ(ガーバー・BOM・部品配置データ)から構成部品を復元し、KiCadで新規に組み直しているものです。

- `reference/NEWDAC_original_BOM.txt` : 元のEagle回路図から書き出された部品表(オリジナル)
- `reference/PnP_NEWDAC_*.txt` : 元の部品配置(Pick & Place)データ

## 回路構成

```
PC --USB--> PCM2704C --(SPDIF)--> DA103C(絶縁トランス) --> AK4118(SPDIFレシーバ)
                                                                  |  I2S
                                                                  v
                                                             AK4490(DAC)
                                                                  |  差動アナログ出力
                                                                  v
                                                       TL072 x3(差動→SE変換 + LPF)
                                                                  |
                                                                  v
                                                              ライン出力
```

- **USB入力**: TI PCM2704CでUSBオーディオを受け、SPDIF出力機能を使って後段に渡す
- **絶縁**: Murata DA103Cパルストランスでガルバニック絶縁
- **SPDIF受信**: AK4118が受信・PLLでクロック再生成、I2Sに変換
- **D/A変換**: AK4490が差動アナログ出力を生成(リファレンス電圧まわりは徹底したデカップリング)
- **出力段**: TL072(デュアルJFETオペアンプ)×3で差動→シングルエンド変換 + LPF
- **電源**: LM1117の3.3V×3・5.0V×1で系統分離、TCM809×2でパワーオンリセットシーケンシング

## 注意事項

- `AK4118` / `AK4490` / `DA103C` のシンボル・フットプリントは、過去に作成した検証済みのEagleライブラリ(ピン配置・パッド番号)を元に復元したもの
- `PCM2704CDBR` のピン番号は公開情報からの推定であり、**未検証**。配線・製造前に必ずデータシートで確認すること
- 実際の配線(ネット接続)はゼロから設計し直したもので、元のオリジナル回路とは異なる可能性がある
