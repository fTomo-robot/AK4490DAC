# AK4490DAC

AKM(旭化成エレクトロニクス)の **AK4490**(32bit プレミアムDAC)と **AK4118**(SPDIFレシーバー)を使ったUSB DACのKiCadプロジェクト。

## 経緯

元の回路図(Eagle形式、`NEWDAC.sch`)はWindows PC上にのみ存在しており、このリポジトリ作成時点では発見できていません。
このプロジェクトは、JLCPCBに発注した際の製造データ(ガーバー・BOM・部品配置データ)から構成部品を復元し、KiCadで新規に組み直した上で、USB入力段・電源・出力段を改良したものです。

- `reference/NEWDAC_original_BOM.txt` : 元のEagle回路図から書き出された部品表(オリジナル、参考用)
- `reference/PnP_NEWDAC_*.txt` : 元の部品配置(Pick & Place)データ(参考用)

## 回路構成(改良版)

```
PC --USB--> SA9227(非同期USBオーディオ) --I2S--------------------+
                                                                  |
   (同軸/光)--SPDIF--> DA103C(絶縁トランス) --> AK4118(SPDIFレシーバ)
                                                    |  I2S        |
                                                    v              v
                                                74LS157(2:1 I2Sセレクタ)
                                                                  |
                                                                  v
                                                             AK4490(DAC)
                                                                  |  差動アナログ出力
                                                                  v
                                                    MUSES8920 x3(差動→SE変換 + LPF)
                                                                  |
                                                                  v
                                                              ライン出力
```

- **USB入力(U2 SA9227)**: Savitech製の非同期USBオーディオストリーミングコントローラ。32bit/384kHzまで対応し、旧PCM2704C(16bit/48kHz止まり)のボトルネックを解消。SPDIF送受信も内蔵
  - **要注意**: SA9227は動作に外部I2C EEPROM(`U8`, 24LC02)へのファームウェア書き込みが必須。書き込み用のファームウェアイメージは別途入手が必要
- **入力切り替え(U7, 74LS157)**: USB(SA9227のI2S出力)とSPDIF(AK4118のI2S出力)を1系統に統合してAK4490へ
- **絶縁(T1, DA103C)**: Murata製パルストランスでSPDIF入力経路をガルバニック絶縁
- **SPDIF受信(U5, AK4118)**: 同軸/光デジタル入力を受信・PLLでクロック再生成しI2Sに変換
- **D/A変換(U6, AK4490)**: 差動電流出力を生成。リファレンス電圧まわりは徹底したデカップリング
- **出力段(IC5-7, MUSES8920)**: 旧TL072から低ノイズ・低歪みのオーディオ用オペアンプに変更(ピン互換のドロップイン)
- **電源(IC1-4, ADP7142)**: 旧LM1117(ノイズ大きめの汎用LDO)から、Analog Devices製の低ノイズLDOに変更。3.3V×3・5.0V×1
- **リセット(U3/U4, TCM809)**: AK4118・AK4490それぞれのパワーオンリセットシーケンシング

## 注意事項

- `AK4118` / `AK4490` / `DA103C` / `SA9227` のシンボル・フットプリントは、旭化成系は過去の検証済みEagleライブラリから、SA9227は公式データシート(Savitech BRAVO-DSD SA9227 v1.3)のピン配置表から復元したもの
- 実際の配線(ネット接続)はまだ行っていない。KiCad上で全ICを配置しただけの状態
- SA9227のファームウェア(EEPROM書き込みイメージ)は別途入手・準備が必要
- ADP7142/MUSES8920/TCM809/BSS138/74LS157はKiCad標準ライブラリのシンボル・フットプリントをそのまま使用
